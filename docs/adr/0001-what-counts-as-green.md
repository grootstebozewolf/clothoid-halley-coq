# What counts as green for a Zenodo mint

A version is minted only when every public **numeric claim** and proof of this work holds, and every other public sentence has been rewritten to match the audit. Softening a false 9,058 / 0.59 µs / “no `Admitted`” is not a fix. Literature dates, product-integration sentences, and DOI pointers are rewritten (human reviews the diff) rather than left in the archived PDF with a release-note disclaimer. Paywalled unread sources are not cited.

**Considered.** Stop on any falsehood until a human edits; split “scientific vs editorial”; ship with a note. Stop would freeze the mint on sentences we can make true. A note would archive the lie. Own-numbers-block / words-rewrite is the last-line-of-defence bar.
